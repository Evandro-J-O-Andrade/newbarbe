# COMP-008 — CTA

Nome: CTA

Objetivo:
Gerar última oportunidade de conversão antes do visitante sair da página.

Responsabilidades:
- Apresentar chamada clara e direta.
- Direcionar para ação principal, preferencialmente WhatsApp.
- Manter destaque visual consistente com a identidade premium.

Dependências:
- Framer Motion
- Lucide React

Em desenvolvimento
