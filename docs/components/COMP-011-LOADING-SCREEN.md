# COMP-011 — Loading Screen

Nome: Loading Screen

Objetivo:
Apresentar uma transição inicial controlada, reforçando a identidade premium antes do conteúdo principal.

Responsabilidades:
- Exibir marca e indicador de carregamento.
- Controlar progresso visual.
- Realizar transição suave para a landing page.

Dependências:
- Framer Motion
- Lucide React

Concluído
