# sitemap.xml

Gerado automaticamente durante o build por `vite-plugin-sitemap`.

Rotas mapeadas:

- `/`
- `/sobre`
- `/servicos`
- `/equipe`
- `/galeria`
- `/agendamento`
- `/contato`

Configuração centralizada em `vite.config.ts`.

## Manutenção

Sempre que adicionar uma rota pública, atualize a lista em `vite.config.ts`.
