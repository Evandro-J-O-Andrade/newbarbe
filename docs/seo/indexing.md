# Indexação

## Estratégia

- Páginas públicas: indexáveis.
- Áreas administrativas: bloqueadas via `robots.txt`.
- Deploy em homologação: `Disallow: /` em `robots.txt`.

## Acompanhamento

- Google Search Console
- Bing Webmaster Tools
- Lighthouse CI

## Observação

Sempre que uma nova seção for criada, avaliar se deve ser indexada e atualizar `robots.txt` e `sitemap.xml`.
