# ADR 002 — Stack do New Wave Barber

## Status

Aceito.

## Contexto

Precisamos de uma stack moderna, produtiva e alinhada à evolução futura do produto.

## Decisão

Usar React + Vite + TypeScript no frontend, com Tailwind CSS v4, Framer Motion, GSAP, React Router, Lucide React e React Hook Form. O backend inicial será simples e independente, sem dependências do `newfastfood`.

## Consequências

- Base profissional e escalável.
- Facilidade para manter e evoluir o site.
- Possibilidade futura de reaproveitar componentes sem herdar acoplamentos.
