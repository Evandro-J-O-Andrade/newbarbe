# Roadmap — New Wave Barber

## Visão geral

O projeto evolui em três módulos principais:

- **Site Público** — Landing Page, SEO, agendamento
- **Portal do Cliente** — Histórico, perfil, avaliações
- **Painel Administrativo** — Dashboard, agenda, barbeiros, cadeiras, financeiro
